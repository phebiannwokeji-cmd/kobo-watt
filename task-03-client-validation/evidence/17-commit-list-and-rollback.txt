6. WHY NAMING THE ID IS SAFER THAN DESCRIBING THE CHANGE IN WORDS
------------------------------------------------------------------------
Describing a change in natural language (such as "undo the referral code change") relies on probabilistic pattern-matching, which invites language models to guess boundaries, accidentally revert unrelated concurrent edits, or hallucinate file states. A Git commit hash is an immutable, mathematically verified cryptographic checksum (SHA-1/SHA-256) of the exact tree delta, guaranteeing that Git inverts precisely the targeted diff without ambiguity or collateral file corruption.
