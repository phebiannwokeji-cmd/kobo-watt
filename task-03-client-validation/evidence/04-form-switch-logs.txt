2. No new session was created on any switch (server has no session middleware

3. No page reload occurs — the server log shows exactly one request per
   "page load". In the browser, switching tabs with history.pushState
   generates no network traffic; the server receives no further requests.
4. The query parameter (?form=signup, ?form=login, ?form=reset) is read
   purely in JavaScript. The server route /auth serves the same auth.html
   regardless of which ?form= value is present.
