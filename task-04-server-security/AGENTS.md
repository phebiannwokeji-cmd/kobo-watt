# Task 4 agent boundaries

- Never run, approve, or trigger a Prisma migration or any other database schema/data change.
- The learner runs each migration manually and saves the command and complete terminal output in `evidence/`.
- You may prepare or review migration files and explain commands, but stop before executing them.
- Never edit a migration after it has been applied. Make a new forward migration instead.
- Do not point Task 4 commands at the Task 3 database.
