6. Server Architecture and Route Whitelist
- Express server bound strictly to loopback 127.0.0.1.
- Default port: 3000 (overrideable via PORT environment variable 1–65535).
- If the port is in use, fail gracefully with an EADDRINUSE message without stopping existing processes.
- Strict routing enabled (app.enable('strict routing')).
- Strict route whitelist using fixed absolute paths via res.sendFile:
  - GET /                            -> public/index.html
  - GET /assets/layout-tokens.css    -> public/assets/layout-tokens.css
  - GET /assets/home.css             -> public/assets/home.css
  - GET /demo                        -> 302 redirect to /demo/
  - GET /demo/                       -> ../task-01-design-system/prototype/index.html
  - GET /demo/index.html             -> ../task-01-design-system/prototype/index.html
  - GET /demo/help.html              -> ../task-01-design-system/prototype/help.html
  - GET /demo/help-no-power.html     -> ../task-01-design-system/prototype/help-no-power.html
  - GET /demo/screen.css             -> ../task-01-design-system/prototype/screen.css
  - GET /demo/demo.js                -> ../task-01-design-system/prototype/demo.js
  - GET /styles/fonts.css            -> ../task-01-design-system/styles/fonts.css
  - GET /styles/tokens.css           -> ../task-01-design-system/styles/tokens.css
  - GET /styles/typography.css       -> ../task-01-design-system/styles/typography.css
  - GET /fonts/SourceSansPro-SemiBold-latin.woff2     -> ../task-01-design-system/fonts/SourceSansPro-SemiBold-latin.woff2
  - GET /fonts/SourceSansPro-SemiBold-latin-ext.woff2 -> ../task-01-design-system/fonts/SourceSansPro-SemiBold-latin-ext.woff2
- All non-whitelisted paths return HTTP 404 with plain text "Not found".
- Never expose the repository root, .git directory, docs, evidence, or tools.
